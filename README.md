# SNS_AutoProgram : SNS 자동화 배포 프로그램 개발
# (유튜브 숏츠 대본, 텍스트 게시물)
//=================================

make 워크플로우 방식으로 파이썬으로 SNS 자동화 프로그램을 만들려고 해.

계정 및 구글 API Key 사용 등 필요한 개발 요소를 정리해 주고 개발 요구서를 작성해줘.

//=================================

Make.com에서 구현하신 **워크플로우**와 **구글 시트 결과물**을 보니 데이터의 흐름과 목적이 아주 명확합니다.

이 파이프라인을 파이썬 스크립트로 전환하면 매일 **업로드하시는 유튜브 영상 콘텐츠**나 **봇 소개 자료**를 다양한 SNS 채널로 확산시키는 자동화 시스템으로 완벽하게 활용하실 수 있습니다. 
특히 평소 다루시는 PyQt5 기반의 커스텀 대시보드 환경에 이 요약 모듈을 통합한다면, 트레이딩 지표와 뉴스 이슈를 한 화면에서 모니터링하는 등 확장성도 매우 뛰어납니다.

성공적인 개발을 위해 필요한 계정 및 환경 요소들을 정리하고, 이를 바탕으로 한 개발 요구사항 정의서(PRD)를 작성해 드립니다.

//=================================

### 파이썬 라이브러리(추가 기능):

1. feedparser (RSS 피드 파싱용)

2. requests, beautifulsoup4 (HTML 웹 크롤링 및 텍스트 정제용)

3. google-generativeai (Gemini API 연동)

4. gspread, oauth2client (구글 시트 연동)

5. python-dotenv (API 키 환경변수 관리)

//=================================
